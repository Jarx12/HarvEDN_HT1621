HT1621		   	
PIN1 VCC (RED) 		-> 5v (SPI1 AZUL)
PIN2 GND (BLACK)	-> GND (SP1 NEGRO)
PIN3 VLCD & BLK (GREEN)	-> 3.3v (PIN5 IZQ ABAJO)
PIN4 RST? (BLACK)	-> GND (SP1 NEGRO)
PIN5 DATA (PURPLE)	-> GPIO04 SPI2 NEGRO
PIN6 WR (YELLOW)	-> GPIO05 SPI2 VERDE
PIN7 CS (BLUE)		-> GPIO07 SPI2 AZUL
2N3904 BASE (BROWN)	-> GPIO08 SPI2 ROJO
